🎌 Ahoninmu Japanese Learning

  • Daily Mission System - 10 unique tasks generated daily
  • Progress Tracking - Monitor completion in real-time
  • Leaderboard Rankings - Monthly competition with medal system

  • 15 Mission Types - Vocabulary, Kanji, Grammar, Reading, Listening, and more
  • Professional UI - Beautiful, responsive design
  • AJAX Updates - No page reload needed
  • Admin Dashboard - Full control over missions and settings

💻 Shortcode Usage

Progress Notification
[ahoninmu_progress]

Displays: "Bạn đã hoàn thành X/Y nhiệm vụ ngày" with progress bar

Daily Missions List
[ahoninmu_missions]

Shows today's missions with Start/Complete buttons

Monthly Leaderboard
[ahoninmu_leaderboard limit="20"]

Displays rankings with medals for top 3 users

🏆 Ranking System

Ranking Formula:

ranking_score = (missions_completed × 100) - (average_time / 10)

This rewards both quantity and speed:

  • Complete more missions to increase your score
  • Finish faster to minimize the time penalty
  • Monthly leaderboard resets each month
  • #1 position highlighted with gold medal 🥇

🎨 User Interface

Features:

1. Upload plugin to /wp-content/plugins/

3. Add shortcodes to pages
4. Start learning!
